## Проверка перед сборкой

Перед каждой сборкой черновика (`/tdd-draft`, шаг «Эталоны») сверяй только номер версии, не читая страницы целиком:

1. `cli`: `python3 <плагин>/scripts/sa_fetch.py version <pageId>` — печатает `pageId`, версию и заголовок. `mcp`: поиск Confluence с CQL `id = <pageId>` — в результате есть `version` и короткий фрагмент, без тела страницы. Чтение страницы целиком для проверки версии не используй: дорого, а на этом Confluence оно ещё и отвечает «нет такой страницы» на доступные страницы.
2. Версия совпадает с колонкой «Версия» — блоки актуальны, дальше не читай.
3. Версия больше — получи разницу между записанной и текущей версией (MCP-инструмент сравнения версий страницы) и прочитай только её. Скажи аналитику, что поменялось и какие блоки из колонки «Блоки» могли устареть. Сборка не останавливается, блоки сам не правь.
4. Версия `—` — сравнивать не с чем: одной строкой в итоге «базовая версия эталона <pageId> не записана», страницу целиком не читай.
5. Страница недоступна (нет прав, нет доступа к Confluence) — одной строкой в итоге, сборка не останавливается.

Новую версию в таблицу записывают при правке плагина, когда блоки сверены с эталоном.
