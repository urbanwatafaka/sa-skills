# Блок: зависимые процессы и сервисы

Секция `05-dependent`.

## Когда

Доработка опирается на уже работающие бизнес-процессы или соприкасается с ними. Иначе секции нет.

## Структура

```markdown
# Зависимые процессы и сервисы

- [Переключение мерчанта в кабинете](https://confluence.example/pages/viewpage.action?pageId=123456) — тем же механизмом пересчитываются права при выборе компании. ‹IM-05›
- Проверка промокода при сохранении анкеты — см. «Процесс: Проверка промокода при сохранении анкеты».
```

## Правила

- Вопреки названию — только бизнес-процессы, не перечень сервисов и БД. Сервис, куда доработка «тоже стучится», упоминается в пункте «Доработок», а не здесь.
- Включай все релевантные процессы, в том числе те, что дорабатываются в этом документе: для них — отсылка к своему «Процесс: …».
- Внешний процесс — гиперссылкой с анкором на страницу в пространстве Payform 2.0 (space `PF2`). Страницу ищи при сборке поиском Confluence по пространству `PF2` — по названию процесса и ключевым сущностям или методам (доступ — `shared/access/adapters.md`). Найденную страницу открой и убедись, что она про этот процесс, а не просто совпала по слову. Не нашлась — пункт текстом без ссылки: что за процесс и что в нём меняется, без вопроса. Несколько кандидатов и по содержанию неясно — один общий `Q-SA` со списком.
- Ссылка на Confluence — всегда гиперссылка с анкором, не голый `pageId`.

## Чек-лист

- [ ] В разделе только процессы, не сервисы и БД.
- [ ] Для каждого внешнего процесса был поиск по `PF2`; найденная ссылка проверена по содержанию.
- [ ] Процессы этого документа ссылаются на свой «Процесс: …».
