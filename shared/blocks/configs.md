# Блок: конфиги

Секция `06-configs`.

## Когда

Доработка добавляет или меняет конфиги, фичефлаги, параметры окружения. Иначе секции нет.

## Структура

```markdown
# Конфиги

| Сервис | Конфиг | Значение | Зачем |
|---|---|---|---|
| `lkp-back` | `PromocodeOwnerCheck:TimeoutMs` | `3000` | Сколько ждать ответа `partners-dashboard` до сохранения без проверки ‹D-02› |
```

## Правила

- Только добавляемые и изменяемые конфиги; у каждого — зачем он нужен.
- Значения — моноширинным; нет утверждённого значения — `ХХХХХ` и `⚠ Q-SA-xx`.
- Имена — из карты влияния или решений, не придумываются.

## Чек-лист

- [ ] Каждый `IM-xx` вида `конфиг` в скоупе есть в таблице.
- [ ] У каждого конфига есть обоснование.
- [ ] Нет конфигов без источника.
