# Блок: доступы

Секция `07-access`.

## Когда

Доработка добавляет или меняет роли и права. Иначе секции нет.

## Структура

```markdown
# Доступы

| Право | Кому | Где проверяется | Хранение |
|---|---|---|---|
| `employees.manage` | Владелец мерчанта | `POST /api/employees`, `lkp-back` | Таблица `prodamus.user_permissions` ‹IM-06› |
```

## Правила

- Конкретные коды прав и механизм хранения (таблица, флаг сессии), не «доступ у администратора».
- Где проверяется — сервис и метод.
- Роли — названия как в системе; роли без изменений не перечисляй.

## Чек-лист

- [ ] Каждый `IM-xx` вида `роль` в скоупе есть в таблице.
- [ ] У каждого права указаны код, место проверки и хранение.
- [ ] Нет общих фраз без кода права.
