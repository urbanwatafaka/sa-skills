# Правила записи артефактов

Общие для `/tdd-impact`, `/tdd-start`, `/tdd-clarify`, `/tdd-draft`, `/tdd-check`, `/tdd-update`. Правила маршрутизации — в `question-routing.md`.

## Пути

В начале стадии выполни `python3 <плагин>/scripts/sa_paths.py`. Файлы задачи читай, пиши и правь только по абсолютному пути `<tasks_dir>/<KEY>/…` из его вывода; пути не собирай сам. В командах скриптов можно использовать `tasks/<KEY>` (рабочая папка — та же). В Bash не используй переменные окружения и составные команды (`;`, `&&`, `|`) — они блокируются; одна команда — один вызов.

## Вопросы

- `questions.md` всегда содержит оба заголовка `## Для PO` и `## Для аналитика` — даже если один пуст. Нет файла — создай с обоими.
- Один вопрос — один пункт списка: `- **<ID>** [<ссылки>] <текст> — *open*` или `— *open, blocking*`. Маркер статуса — в конце той строки пункта, где он стоит; продолжение (варианты, «где проверить») — строки с отступом.
- В вопросах PO ссылки `R-xx`/`IM-xx`/`D-xx` — только в начале в `[...]`, не в тексте и не в продолжении; текст без названий сервисов, полей, методов. Ссылки на вопросы (`Q-PO-xx`) в тексте допустимы.
- Новые вопросы дописывай в конец своей секции: `Q-PO` — в `## Для PO`, `Q-SA` — в `## Для аналитика`.
- Существующие вопросы не переписывай и не перенумеровывай; меняется только маркер статуса (`*open*`/`*open, blocking*` на `*answered*`/`*obsolete*`).

## Ссылки

- `Q-PO`: `R-xx` из BRD или колонки `← R` строки карты; допустим и `IM-xx`.
- `Q-SA`: `IM-xx` или `R-xx`.
- `[BRD]` — только для отсутствующих пунктов BRD.
- ID не выдумывай: каждая ссылка должна существовать.

## ID

Сначала собери полный список новых строк одного вида, затем ровно один вызов `python3 <плагин>/scripts/sa_ids.py next tasks/<KEY> <вид> <N>` на вид и сразу запиши эти строки. Не вызывай `sa_ids.py` дважды для одного вида до записи — ID повторятся. Новых строк нет (N=0) — вызова нет.

## Таблицы

Символ `|` внутри ячеек и текста вопросов не используй.

## Повторный запуск

Артефакты обновляй на месте: сохраняй существующие ID и правки человека, не переписывай с нуля.
